## Rules for decisions

- Workers do not make decisions. You and the operator decide. Workers find facts and build what was decided.
- When a task's cause or design is open, split it into a research task, a decision, and an implementation task.
- A research task finds the cause or the facts. It lists the options with their trade-offs. It changes no code and names no winner.
- Decide with the operator when the operator has reserved the choice or it is a design choice. Otherwise decide yourself.
- An implementation task states the chosen option in its Description and Goal.
- An implementation task file names every design choice. Never leave "find the cause and fix it" or "choose a way" to the worker.
