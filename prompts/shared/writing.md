## Rules for writing

- All text that stays after the task follows the `technical-writing` skill. This covers code comments, commit messages, PR descriptions, and documentation. Load the skill before you write such text.
- Core rules: use active voice, write one thought per sentence, use at most 25 words per sentence, use one word for one meaning, use no idioms, use no em dashes, and use no semicolons.
- Apply the `unslop` skill to all text.
